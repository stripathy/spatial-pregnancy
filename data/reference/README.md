# Reference Data

## Files in this directory

### `valid_celltypes_zeng_4sections.csv`
List of valid cell types (class, subclass, supertype) present in the 4 coronal Zeng MERFISH reference sections used for annotation. These sections span the forebrain and are the basis for region-restricting our classification centroids.

**Reference sections:** `C57BL6J-638850.46`, `.47`, `.48`, `.49` from the Allen Brain Cell Atlas (ABCA) MERFISH dataset.

**Columns:**
- `class`, `subclass`, `supertype` — taxonomy level names (Allen Brain Cell Atlas WMB taxonomy, release 2023-08-21)
- `class_color`, `subclass_color`, `supertype_color` — Allen Institute hex color codes for each type
- `n_cells_ref` — number of cells of this supertype in the 4 reference sections

**Summary (343,947 total reference cells):**

| Level | Count |
|-------|-------|
| Classes | 24 |
| Subclasses | 135 |
| Supertypes | 502 |

The 10 classes **excluded** by region restriction (not present in these 4 forebrain sections) are hindbrain/midbrain types:
- `16 HY MM Glut`, `17 MH-LH Glut`, `21 MB Dopa`, `22 MB-HB Sero`, `25 Pineal Glut`, `26 P GABA`, `27 MY GABA`, `28 CB GABA`, `29 CB Glut`, `32 OEC`

### `gene_symbol_to_ensembl_mouse.json`
Mapping of 25,209 mouse gene symbols to Ensembl gene IDs. Built from Ensembl BioMart. Used to map query gene symbols to the Ensembl IDs in the Allen precomputed stats file.

### Files NOT tracked (too large for git)

These must be downloaded or copied manually:

#### `precomputed_stats_ABC_revision_230821.h5` (1.4 GB)
Precomputed statistics for the Allen WMB taxonomy. Contains per-cluster mean expression (5,322 clusters × 32,285 genes) that we use to build classification centroids.

**Download:** https://allen-brain-cell-atlas.s3.us-west-2.amazonaws.com/mapmycells/WMB-taxonomy/20240831/precomputed_stats_ABC_revision_230821.h5

#### `adata_ref_zeng_imputed.h5ad` (5.5 GB)
The 4-section Zeng MERFISH reference atlas (343,947 cells × 2,643 imputed genes) with full metadata including spatial coordinates, cell type labels, and Allen CCF parcellation annotations.

This file is generated by subsetting the full Allen MERFISH imputed dataset (`C57BL6J-638850-imputed-log2.h5ad`, 47 GB) to the 4 target sections. See Keon Arbabi's [spatial-pregnancy-analysis](https://github.com/keon-arbabi/spatial-pregnancy-analysis) repo (`merfish_prep_atlases.py`) for the preparation pipeline.

**Source data:** https://allen-brain-cell-atlas.s3.us-west-2.amazonaws.com/expression_matrices/MERFISH-C57BL6J-638850-imputed/20240831/C57BL6J-638850-imputed-log2.h5ad
