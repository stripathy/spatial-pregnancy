# spatial-pregnancy

Cell type annotation and compositional analysis for maternal brain spatial transcriptomics.

## Overview

This repo provides a pipeline for annotating spatial transcriptomics data (MERFISH, Slide-tags, Xenium 5k) using the Allen Brain Cell Atlas (ABC) whole mouse brain taxonomy. It then performs compositional testing (via crumblr) to identify cell type proportion changes across pregnancy conditions.

## Pipeline

### 1. Cell Type Annotation (`code/annotate.py`)

Annotates query cells using region-restricted snRNAseq centroids from the ABC taxonomy.

**Methods:**
- **Pearson correlation** — for targeted panels (MERFISH 496 genes, Xenium 5k)
- **Spearman correlation** — for genome-wide data (Slide-tags 32K genes)
- **Hierarchical** — classify to class first, then subclass/supertype within class

**Reference:**
- Centroids derived from `precomputed_stats_ABC_revision_230821.h5` (cluster-level mean expression for 5,322 clusters × 32,285 genes)
- Restricted to cell types present in 4 Zeng MERFISH reference sections (C57BL6J-638850.46-.49): 24 classes, 135 subclasses, 502 supertypes

```bash
# MERFISH (targeted panel → Pearson)
python code/annotate.py \
  --input data/merfish_query.h5ad \
  --output output/merfish_annotated.h5ad \
  --method pearson

# Slide-tags (genome-wide → Spearman)
python code/annotate.py \
  --input data/slidetags_query.h5ad \
  --output output/slidetags_annotated.h5ad \
  --method spearman
```

### 2. Benchmarking (`code/benchmark.py`)

Compares annotations against CAST labels and Zeng MERFISH reference proportions.

**Metrics:**
- Agreement with CAST class/subclass labels
- Proportion correlation vs Zeng reference (Pearson r on cell type frequencies)
- Spatial coherence (fraction of k=20 nearest neighbors with same label)

```bash
python code/benchmark.py \
  --input output/merfish_annotated.h5ad \
  --output output/merfish_benchmarks.csv
```

### 3. Compositional Testing (`code/build_crumblr_input.py` + `code/run_crumblr.R`)

Tests for cell type proportion changes across conditions using crumblr + dream.

```bash
# Build input CSVs
python code/build_crumblr_input.py

# Run crumblr in R
Rscript code/run_crumblr.R
```

**Design:** `~ condition` (CTRL vs PREG vs POSTPART)
**Contrasts:** PREG vs CTRL, POSTPART vs CTRL, POSTPART vs PREG
**Strata:** whole composition, neuronal-only, non-neuronal-only

### 4. Convert Seurat RDS to h5ad (`code/convert_rds_to_h5ad.py`)

For converting large Seurat objects from R. Requires rpy2 + R with Seurat installed.

```bash
python code/convert_rds_to_h5ad.py --input data/objf_raw.rds --output data/xenium5k.h5ad
```

## Data Requirements

Place these in `data/`:
- Query h5ad files (MERFISH, Slide-tags, Xenium 5k)
- `genename_mapping_merfish_panel.csv` — MERFISH gene symbol → Ensembl mapping

Place these in `data/reference/`:
- `precomputed_stats_ABC_revision_230821.h5` — [download from Allen Institute](https://allen-brain-cell-atlas.s3.us-west-2.amazonaws.com/index.html#mapmycells/WMB-taxonomy/20240831/)
- `gene_symbol_to_ensembl_mouse.json` — general symbol → Ensembl mapping

Place the Zeng reference in `output/data/`:
- `adata_ref_zeng_imputed.h5ad` — 4-section Zeng MERFISH reference (generated by `code/prep_reference.py`)

## Key Findings

### Annotation Performance

| Dataset | Method | Class agree | Subclass agree | Prop corr (class) | Spatial coherence |
|---------|--------|-------------|----------------|--------------------|--------------------|
| MERFISH (n=9) | Hierarchical Pearson | 65.2% | 47.4% | 0.861 | 0.345 |
| Slide-tags (n=8) | Hierarchical Spearman | 82.4% | 48.6% | 0.929 | 0.335 |
| CAST baseline | — | — | — | 0.713 / 0.944 | 0.442 / 0.374 |

- Spearman correlation is essential for genome-wide Slide-tags data (82.4% vs 56.1% class agreement with Pearson)
- CAST has higher spatial coherence (uses spatial graph neural network)
- Our methods have higher proportion correlation with the reference atlas

### Compositional Changes

With only n=3 per condition, no results survive FDR correction. Nominal findings:
- Endothelial cells (333 Endo NN) show expected PREG increase in MERFISH CAST annotations (5.1% → 7.5% → 3.8%)
- Strongest compositional signals in lateral septal GABA types in Slide-tags
